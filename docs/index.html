Explicit SoC modules

See every system path, not only the accelerators.

Named transaction-level modules expose control, translation, coherence, memory, completion and power-management decisions.

Control

RISC-V SMP cluster & PLIC

CPU MMIO programs each accelerator. Completion is raised through the explicit interrupt controller and delivered back to the CPU cluster.

Data movement

IOMMU & DMA paths

Every non-stream DMA read/write performs explicit descriptor translation before it reaches the selected memory subsystem.

Coherence

Directory / flush manager

Coherent DMA and coherent-plus-flush jobs create separate coherence-probe transactions before their LLC access.

Interconnect

Mesh NoC with VC buffers

Separate traffic planes, hops, serialization, VC credit pressure and clock-domain crossings contribute to timing.

Memory & power

LLC, SPAD, DDR & DHPM

Queued memories and token-based V/F allocation show the cost of placement, bandwidth and accelerator concurrency.

Compute

23 named accelerator tiles

NVDLA, FFT, audio, AES, Viterbi, NLP, vision, crypto and other endpoints are explicit AT components; datapaths remain abstract timing models.

Approximately timed engine

Non-blocking transport, clearly traceable.

Every transaction follows the standard four-phase AT handshake. The simulator records an event trace for timing analysis.

BEGIN_REQInitiator injects a transaction into the request plane.
END_REQTarget accepts it after NoC and buffer delay.
BEGIN_RESPTarget produces completion after service latency.
END_RESPInitiator receives the return packet and retires it.

Workload catalogue

Nine executable workload cases.

Four architecture-stress traces and five ADAS pipelines are defined in the configuration scenarios block and can be run without changing simulator code.

baseline

Five parallel jobs

Vision, NLP, GPS, AES and analytics with non-coherent DMA through a single LLC/DRAM path.

llc_spad

Partitioned memory

The same five applications with SPAD, coherent DMA and coherent-plus-flush traffic.

direct_stream

Audio decode → FFT

A producer-consumer chain that directly streams data between accelerator tiles.

dhpm_5accel

Five-way concurrency

NVDLA, NLP, vision, crypto and Viterbi contend for global power tokens and memory resources.

adas_front_perception

Front camera perception

ISP, vehicle/pedestrian detection, lane segmentation, traffic signs, tracking, EKF and collision risk.

adas_driver_monitoring

In-cabin monitoring

NIR ISP, face/head-pose, eye-gaze/blink, hand tracking, driver state and attention alert.

adas_surround_fusion

Surround sensor fusion

Front/side perception, radar FFT, IMU-visual EKF, BEV fusion, world tracking and hazard decision.

adas_pilotnet_control

End-to-end control

PilotNet-style steering, throttle and brake decision alongside lane geometry.

adas_event_hazard

Event hazard perception

Event denoising, temporal object/lane perception, tracking and safety alert.

Get started

Run the model in minutes.

The Python model runs without external simulation dependencies. A companion native SystemC AT reference shows how the same protocol maps to TLM-2.0.

# inspect the supplied workload cases
$ python3 experiments/list_workloads.py

# run every AT workload
$ python3 experiments/run_at_all.py

# verify the model
$ python3 -m unittest discover -s tests -v
