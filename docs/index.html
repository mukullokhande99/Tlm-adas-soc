Approximately timed engine

Non-blocking transport, clearly traceable.

Every transaction follows the standard four-phase AT handshake. The simulator records an event trace for timing analysis.

BEGIN_REQInitiator injects a transaction into the request plane.
END_REQTarget accepts it after NoC and buffer delay.
BEGIN_RESPTarget produces completion after service latency.
END_RESPInitiator receives the return packet and retires it.

Get started

Run the model in minutes.

The Python model runs without external simulation dependencies. A companion native SystemC AT reference shows how the same protocol maps to TLM-2.0.

# clone the source and run all AT scenarios
$ git clone https://github.com/mukullokhande99/Tlm-adas-soc.git
$ cd Tlm-adas-soc
$ python3 experiments/run_at_all.py

# verify the model
$ python3 -m unittest discover -s tests -v
